# Tóth Katalin Enikő – Online önéletrajz
https://tothkatica.github.io/Oneletrajz/


Reszponzív, magyar és angol nyelven elérhető online önéletrajz, amely bemutatja tanulmányaimat, készségeimet, projektjeimet és tapasztalataimat.

Az oldal interaktív elemeket, nyelvváltási lehetőséget és mobilbarát megjelenést tartalmaz.

**Felhasznált technológiák:** HTML, CSS, JavaScript, W3.CSS.
